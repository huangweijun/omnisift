# Metrics

Weekly reports generated by `Growth/scripts/weekly_report.mjs` belong here.

Initial manual inputs:

- Google Search Console impressions and clicks
- Bing Webmaster Tools impressions and clicks
- indexed pages
- AI/search referrals noticed in server logs or Cloudflare analytics
- App Store product page views after launch
- downloads after launch
- first-card activation count if available
- subscription conversions if available

Keep this simple until the funnel has real traffic.
